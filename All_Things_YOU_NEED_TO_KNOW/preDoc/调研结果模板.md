> 在大模型与 AI Agent 技术快速发展的背景下，多 Agent 协作已成为提升复杂任务执行效率的关键趋势。本课题聚焦 AI 驱动的开发与协作场景，要求基于统一适配器层与主流 Agent 平台（如 Claude Code、Codex），打造一个 IM 聊天式的多 Agent 协作平台（AgentHub）。
