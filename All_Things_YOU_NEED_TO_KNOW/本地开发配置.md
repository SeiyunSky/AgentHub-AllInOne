## 一、必装软件清单

### 1. Python 3.11+

**用途**：后端运行时

- **下载**：https://www.python.org/downloads/
- **版本要求**：>= 3.11（推荐 3.12）— `asyncio.TaskGroup` 在 3.11+ 才有
- **安装注意**：勾选 "Add Python to PATH"
- **验证**：
  ```bash
  python --version
  # Python 3.12.x
  ```

---

### 2. MySQL 8.0+

**用途**：主数据库

- **下载**：https://dev.mysql.com/downloads/installer/
- **包**：`mysql-installer-community-8.0.x.msi`（约 600MB 完整版）
- **安装步骤**：
  1. 运行 installer，选 **"Server only"** 模式
  2. Setup Type: Development Computer
  3. 端口：3306（默认）
  4. Authentication Method: **Use Strong Password Encryption**（默认）
  5. 设置 root 密码 — **记住这个密码**
  6. Windows Service: 勾选 "Start at System Startup"
- **验证**：
  ```bash
  mysql -u root -p
  # 输入密码后能进 mysql> 提示符
  ```
- **创建数据库**：
  ```sql
  CREATE DATABASE agenthub CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
  ```

**Docker 替代方案**（如已装 Docker Desktop）：
```bash
docker run -d --name agenthub-mysql \
  -e MYSQL_ROOT_PASSWORD=your_password \
  -e MYSQL_DATABASE=agenthub \
  -p 3306:3306 \
  mysql:8.0
```

---

### 3. Node.js 20+

**用途**：前端构建 + Codex CLI 依赖

- **下载**：https://nodejs.org/（选 LTS 版本）
- **版本要求**：>= 20
- **验证**：
  ```bash
  node --version
  npm --version
  ```

---

### 4. Git

**用途**：版本控制（应该已经装好）

- **下载**：https://git-scm.com/download/win
- **验证**：
  ```bash
  git --version
  ```

---

### 5. Codex CLI（仅无履生需要装）

**用途**：CodexAdapter 通过 `codex mcp-server` 子进程调用

- **安装**：
  ```bash
  npm install -g @openai/codex
  ```
- **验证**：
  ```bash
  codex --version
  ```

---

### 6. IDE 推荐

- **后端**：PyCharm Community / VS Code + Python 扩展
- **前端**：VS Code + Volar 扩展（Vue 3 支持）
- **数据库**：DataGrip / DBeaver / MySQL Workbench

## 二、可选但推荐

### Redis（MVP 阶段不强制）

MVP 实现时用内存代替 Redis 接口，Phase 3 上线前再装。

- **Windows 下载**：https://github.com/microsoftarchive/redis/releases（旧版）
- **推荐用 Docker**：
  ```bash
  docker run -d --name agenthub-redis -p 6379:6379 redis:7
  ```

## 三、Python 依赖安装

进入 `backend/` 目录：

```bash
cd backend
python -m venv .venv
.venv\Scripts\activate           # Windows
# source .venv/bin/activate      # Mac/Linux

pip install -r requirements.txt
```

---

## 四、环境变量配置

在 `backend/` 目录创建 `.env` 文件（**不要提交到 git**）：

```env
# 数据库
DB_URL=mysql+pymysql://root:你的密码@localhost:3306/agenthub

# JWT
JWT_SECRET=随便一段长字符串
JWT_ALGORITHM=HS256
JWT_EXPIRE_MINUTES=1440

# LLM API Keys
ANTHROPIC_API_KEY=sk-ant-xxx
OPENAI_API_KEY=sk-xxx

# 其他
LOG_LEVEL=INFO
```

仓库里会有 `.env.example` 作为模板，复制改名即可。

## 五、首次启动流程

### 后端

```bash
cd backend
.venv\Scripts\activate

# 1. 跑数据库迁移（建表）
alembic upgrade head

# 2. 启动服务
uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

启动成功后访问 http://localhost:8000/docs 看 Swagger 文档。

### 前端

```bash
cd frontend
npm install
npm run dev
```

启动成功后访问 http://localhost:5173

## 六、常用开发命令

### 数据库迁移

```bash
# 修改了 ORM 类后，生成迁移文件
alembic revision --autogenerate -m "描述这次改动"

# 应用迁移到本地数据库
alembic upgrade head

# 回滚一个版本
alembic downgrade -1
```

### 测试

```bash
pytest                          # 跑所有测试
pytest tests/integration/       # 只跑集成测试
pytest -v -k test_chat          # 跑名字含 test_chat 的
```

## 七、新成员加入流程速查

1. 装 Python 3.11+ / MySQL 8.0+ / Node.js 20+
2. clone 仓库
3. 创建 `agenthub` 数据库
4. 复制 `.env.example` 为 `.env`，填密码 + API Keys
5. `cd backend && python -m venv .venv && .venv\Scripts\activate && pip install -r requirements.txt`
6. `alembic upgrade head` — 建表
7. `uvicorn main:app --reload` — 启动后端
8. `cd ../frontend && npm install && npm run dev` — 启动前端
9. 访问 http://localhost:5173 看到登录页 = 成功
