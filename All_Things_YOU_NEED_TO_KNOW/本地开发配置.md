## 一、必装软件清单

### 1. Python 3.11+

**用途**：后端运行时

- **下载**：https://www.python.org/downloads/
- **版本要求**：>= 3.11（推荐 3.12；3.13 在 Windows 下有已知 `UV_HANDLE_CLOSING` 断言，偶发不影响功能）
- **安装注意**：勾选 "Add Python to PATH"
- **验证**：
  ```bash
  python --version
  # Python 3.12.x
  ```

---

### 2. MySQL 8.0+

**用途**：主数据库

- **下载**：https://dev.mysql.com/downloads/installer/
- **安装步骤**：
  1. 运行 installer，选 **"Server only"** 模式
  2. 端口：3306（默认）
  3. 设置 root 密码 — **记住这个密码**
  4. Windows Service: 勾选 "Start at System Startup"
- **验证**：
  ```bash
  mysql -u root -p
  # 输入密码后能进 mysql> 提示符
  ```

> 无需手动建库，后端启动时会自动执行 `CREATE DATABASE IF NOT EXISTS agenthub`。

**Docker 替代方案**（如已装 Docker Desktop）：
```bash
docker run -d --name agenthub-mysql \
  -e MYSQL_ROOT_PASSWORD=your_password \
  -e MYSQL_DATABASE=agenthub \
  -p 3306:3306 \
  mysql:8.0
```

---

### 3. Docker Desktop

**用途**：Agent 沙箱容器（`deploy_app` 工具依赖）

- **下载**：https://www.docker.com/products/docker-desktop/
- **说明**：不装 Docker Desktop 时，`deploy_app` 工具不可用，其余功能正常。后端启动时会自动检测并给出 warning，不阻塞主流程。
- **验证**：
  ```bash
  docker info
  ```

### 4. Node.js 20+

**用途**：前端构建

- **下载**：https://nodejs.org/（选 LTS 版本）
- **验证**：

  ```bash
  npm --version
  ```

### 5. Claude Code CLI

**用途**：ClaudeAdapter，内置 Agent 全部依赖此 CLI。**不装则内置 Agent 无法运行。**

- **安装**：

- **登录**（首次，需要 Anthropic 账号）：
  ```bash
  claude login
  ```
- **验证**：
  ```bash
  claude --version
  ```

## 二、可选

### Redis

SSE 事件回放缓冲用（刷新页面能恢复 streaming 中的消息）。不装则静默降级，回放功能不可用，其余正常。

```bash
docker run -d --name agenthub-redis -p 6379:6379 redis:7
```

`.env` 里配置：
```env
REDIS_URL=redis://localhost:6379/0
```

## 四、环境变量配置

复制 `backend/.env.example` 为 `backend/.env`（**不要提交到 git**），关键字段：

```env
# 数据库
DB_URL=mysql+pymysql://root:你的密码@localhost:3306/agenthub

# CORS（前端地址）
CORS_ALLOWED_ORIGINS=http://localhost:5173

# 主 Agent Orchestrator LLM（走 Anthropic 兼容协议，三选一）

# 方案 A：直连 Anthropic 官方
EXTERNAL_API_BASE=https://api.anthropic.com
EXTERNAL_API_KEY=sk-ant-xxx
EXTERNAL_MODEL=claude-sonnet-4-6

# 方案 B：Moonshot Kimi（国内可直连，但免费 key RPM 很低，容易触发 429 等 60s 重试）
# EXTERNAL_API_BASE=https://api.moonshot.cn/anthropic
# EXTERNAL_API_KEY=sk-xxx
# EXTERNAL_MODEL=kimi-k2.5

# 方案 C：本地 LiteLLM / 其他 Anthropic 兼容代理
# EXTERNAL_API_BASE=http://localhost:6655/anthropic
# EXTERNAL_API_KEY=any
# EXTERNAL_MODEL=claude-sonnet-4-6

# 子 Agent Adapter（按需填，不用的留空）
# ANTHROPIC_API_KEY=sk-ant-xxx     # ClaudeAdapter（Claude Code CLI）
# OPENAI_API_KEY=sk-xxx            # CustomAdapter（OpenAI 兼容）
# OPENAI_BASE_URL=https://api.openai.com/v1
# OPENAI_MODEL_ID=gpt-4o
```

## 五、首次启动流程

### 后端

```bash
# 在项目根目录，先激活 venv
cd backend && .venv\Scripts\activate && cd ..

# 建表（首次或有新 migration 时执行，在 backend/ 目录下运行）
cd backend && alembic upgrade head && cd ..

# 启动（必须在项目根目录用 run.py）
python run.py
```

> **注意**：不要用 `uvicorn main:app` 直接启动，Windows 事件循环策略在 `run.py` 里统一设置。

启动成功后访问 http://localhost:18888/docs 看 Swagger 文档。

### 前端

```bash
cd frontend
npm install
npm run dev
```

启动成功后访问 http://localhost:5173

## 六、常用开发命令

### 数据库迁移（在 backend/ 目录下执行）

```bash
# 修改了 ORM 类后，生成迁移文件
alembic revision --autogenerate -m "描述这次改动"

# 应用迁移
alembic upgrade head

# 回滚一个版本
alembic downgrade -1
```

### 测试（在 backend/ 目录下执行）

```bash
pytest                          # 跑所有测试
pytest tests/integration/       # 只跑集成测试
pytest -v -k test_chat          # 跑名字含 test_chat 的
```

## 七、新成员加入流程速查

1. 装 Python 3.11+ / MySQL 8.0+ / Docker Desktop / Node.js 20+
2. `npm install -g @anthropic-ai/claude-code` 然后 `claude login`
3. clone 仓库
3. `cd backend && python -m venv .venv && .venv\Scripts\activate && pip install -r requirements.txt`
4. 复制 `backend/.env.example` 为 `backend/.env`，填 DB 密码 + `EXTERNAL_API_*`
5. `alembic upgrade head`（在 backend/ 目录）
6. `cd .. && python run.py` — 启动后端
7. `cd frontend && npm install && npm run dev` — 启动前端
8. 访问 http://localhost:5173 看到登录页 = 成功

## 八、踩坑记录

### 直接用 `uvicorn main:app` 启动，Windows 下 shutdown 报 `UV_HANDLE_CLOSING` 断言

必须用项目根目录的 `run.py` 启动，它统一设置了 `asyncio.WindowsProactorEventLoopPolicy` 并传 `loop="asyncio"` 给 uvicorn。

### Moonshot `kimi-k2.5` 返回 429，日志显示 "Retrying in 60 seconds"

免费 key RPM 配额打满。换 `EXTERNAL_API_BASE` 为 Anthropic 官方，或升级 Moonshot 账号配额。

### 消息发送后卡住不显示，F5 刷新才正常

已在 2026-06-08 修复（后端 `chat.py` SSE 端点过早关闭连接导致事件丢失）。如还复现请检查后端是否为最新代码。

### `deploy_app` 工具报错 "Docker daemon 不通"

确认 Docker Desktop 已启动。后端会在启动时 warning 一次，功能等 Docker 启动后自动恢复，不需要重启后端。

### Vite 启动报 CSS ENOENT 找不到某个 SVG/图片

旧 Vite 缓存残留。执行：
```bash
rm -rf frontend/node_modules/.vite
```
然后重新 `npm run dev`。
