## 一、技术选型

| 项目 | 选型 | 理由 |
|---|---|---|
| 框架 | Vue 3 + TypeScript | 其他的不是很熟，react高级特性比较难用 |
| 状态管理 | Pinia | 适配Vue3 |
| UI 样式 | Tailwind CSS | 快速布局 |
| 组件库 | Element Plus | 生态最全 |
| SSE 客户端 | @microsoft/fetch-event-source | 支持 POST + 自定义 header（JWT） |
| WebSocket | 原生 WebSocket 封装 | 状态/审批/Diff结果推送 |
| HTTP 请求 | Axios | CRUD 操作，JWT 拦截器 |
| 路由 | Vue Router | /chat/:conversationId + /agents + /login，支持浏览器前进后退、刷新保留会话 |
| 构建 | Vite | Vue 3 官方配套，HMR 快 |

## 四、SSE 事件 → 前端处理映射

| 后端事件 | chatStore action | 前端效果 |
|---|---|---|
| `agent_start` | `addStreamingMessage` | 新建气泡，加入streamingIds |
| `token` | `appendToken` | 按agentId找气泡，追加content |
| `artifact_html` | `setArtifactHtml` | 气泡内插入PreviewCard（sandboxed iframe） |
| `artifact_diff` | `setArtifactDiff` | 气泡内插入DiffCard（红绿diff行） |
| `approval_request` | `addApprovalRequest` | 气泡内插入ApprovalCard，Thread暂停等待 |
| `deploy_progress` | `updateDeployProgress` | DeployCard进度条更新 |
| `deploy_done` | `updateDeployProgress` | DeployCard显示完成URL |
| `agent_done` | `finishStreaming` | streaming光标消失，气泡结束态 |
| `agent_error` | `setAgentError` | 气泡显示错误提示 |
| `round_done` | `clearRound` | agentBubbles清空，本轮结束 |

### WebSocket 事件映射

| 后端推送 | 前端处理 |
|---|---|
| `diff_applied {status: success}` | `ui.diffCardStates` 更新为 applied |
| `diff_applied {status: conflict}` | `ui.diffCardStates` 更新为 conflict，显示冲突提示 |
| 审批确认结果 | `pendingApprovals` 删除对应条目，ApprovalCard更新状态 |

## 五、产物卡片

| 卡片 | 触发事件 | 交互 |
|---|---|---|
| `PreviewCard` | `artifact_html` | sandboxed iframe内联 → 点击全屏展开到右栏 |
| `DiffCard` | `artifact_diff` | 文件名+红绿行 → 一键应用按钮 → WebSocket确认结果 |
| `DeployCard` | `deploy_progress/done` | 阶段进度条 → 完成后显示预览URL |
| `ApprovalCard` | `approval_request` | 操作描述 → 确认/拒绝按钮 → WebSocket发送结果 |

**PreviewCard 安全**：`<iframe sandbox="allow-scripts">` 禁止表单提交、禁止顶层导航、禁止同源访问，防 XSS。参考 LobeChat Artifacts 方案。
