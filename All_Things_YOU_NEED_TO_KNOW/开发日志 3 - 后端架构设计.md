## 一、技术选型

| 层 | 选型 | 理由 |
|---|---|---|
| 后端框架 | Python FastAPI | asyncio原生支持并行流，LLM SDK生态完整 |
| 多Agent并行SSE | asyncio.TaskGroup + asyncio.Queue | merge_async_generators模式 |
| 消息持久化 | MySQL + SQLAlchemy + Alembic | 团队熟悉，结构化消息查询，Alembic管迁移 |
| 流式缓冲/断点恢复 | Redis | token缓冲 + checkpoint热缓存 |
| 分布式锁 | Redis | 同一会话防并发重入 |
| 熔断器 | 自实现 circuit_breaker | CLOSED→OPEN→HALF_OPEN三态 |
| Claude接入 | Anthropic Python SDK直调 | 流式SSE透传，approval事件映射 |
| Codex接入 | codex mcp-server子进程 + Python MCP SDK | 官方推MCP集成，长期稳定，接入成本低 |
| Custom Agent | OpenAI兼容API | 自定义System Prompt + Tools + MCP |
| Prompt/Skill内容 | Markdown文件（带frontmatter） | 内容与代码分离，git版本化 |
| 向量记忆 | Chroma（接口隔离，可替换） | 长期记忆跨对话检索 |
| 鉴权 | JWT + Redis session blacklist | 登出加黑名单，Agent权限按用户隔离 |

## 三、完整工作流

### 3.1 chat_service 三条路由分支

```
收到 ChatRequest
  解析 @提及列表 mention_ids
  判断 selected_range 是否存在

  if selected_range 不为空:
      → 对话式局部修改流程

  elif conversation.mode == 'single':
      → 单聊流程

  elif len(mention_ids) == 1 and conversation.mode == 'group':
      → @个体特化流程（直通，不走Orchestrator）

  else:
      → 群聊全员流程（走Orchestrator）
```

---

### 3.2 单聊流程

```
用户发消息
│
├─ api/v1/chat.py
│    JWT校验 → 参数校验(ChatRequest) → 建立SSE连接
│
├─ services/chat_service.py
│    mode=single，core/lock.py 拿 conversation 分布式锁
│
├─ services/thread_service.py
│    创建 Thread(status=init) → repositories/thread_repo.py 写MySQL
│
├─ services/skill_service.py
│    查询该Agent挂载的Skill
│    按任务关键词匹配（progressive disclosure，只注入匹配的Skill）
│
├─ services/prompt_service.py
│    加载 prompts/<agent>.md 模板
│    渲染变量：{{user_name}} / {{skills}} / {{history}}
│    输出最终Prompt字符串
│
├─ core/circuit_breaker.py 检查熔断状态
│    OPEN → 直接返回熔断错误，降级提示
│    CLOSED/HALF_OPEN → 继续
│
├─ adapters/registry.py → adapters/claude.py 或 adapters/codex.py
│    hooks/pre_execution.py（限流/审批检查）
│    Thread status → running
│    stream(prompt, history, skills) → AgentEvent流
│
├─ AgentEvent 逐条处理
│    token
│      → repositories/stream_buffer_repo.py 写Redis缓冲（断点恢复用）
│      → services/stream_service.py SSE推前端
│
│    artifact_html / artifact_code
│      → hooks/post_execution.py 识别产物类型
│      → services/preview_service.py 生成预览URL
│      → services/message_service.py 写artifact消息(content_type=artifact_html)
│      → services/stream_service.py SSE推前端渲染预览卡片
│
│    artifact_diff
│      → hooks/post_execution.py
│      → services/diff_service.py
│      → repositories/git_repo.py 生成diff
│      → services/message_service.py 写diff消息(content_type=artifact_diff)
│      → services/stream_service.py SSE推前端渲染Diff卡片
│
│    approval_request
│      → hooks/approval.py
│      → Thread status → suspended
│      → WebSocket推前端渲染审批Action按钮
│      → 等待用户确认（ws.py收到确认）→ Thread resume → 继续stream
│
│    sub_agent_spawn
│      → services/sub_agent_service.py
│      → 创建子Thread(parent_thread_id=当前Thread)
│      → 递归走 skill→prompt→adapter 链路
│      → 子Thread结果回收合并回父Thread上下文
│
│    agent_done
│      → Thread status → done
│      → repositories/stream_buffer_repo.py 清Redis缓冲
│      → core/lock.py 释放conversation锁
│
└─ services/message_service.py
     消息status: streaming → done → repositories/message_repo.py 落MySQL
```

### 3.3 群聊全员流程（并行多Agent）

```
用户 @Claude @Codex 发消息（或不@，由Orchestrator分派）
│
├─ services/chat_service.py → services/orchestrator_service.py
│    core/lock.py 拿conversation锁
│
├─ services/orchestrator_service.py
│    调LLM意图识别，输出结构化JSON任务计划：
│      {"tasks":[
│        {"agentId":"claude","prompt":"负责后端架构设计"},
│        {"agentId":"codex", "prompt":"负责代码实现"}
│      ], "mode":"parallel"}
│    JSON解析失败 → 降级为单Agent（claude兜底）
│
├─ services/thread_service.py
│    每个task创建一个Thread(parent_id=当前消息id)
│    repositories/thread_repo.py 批量写MySQL
│
├─ asyncio.TaskGroup 并行启动所有Thread
│    asyncio.Queue 合并多路AgentEvent流
│    每个事件携带agentId → 前端按agentId路由到对应气泡
│    各Thread独立走 skill→prompt→adapter 链路
│
├─ 某个Agent失败
│    core/circuit_breaker.py 记录失败
│    orchestrator_service 降级：
│      该Agent标记error消息推前端
│      其他Agent继续，不中断整轮
│
└─ 所有Thread done
     services/stream_service.py 推 round_done 事件
     core/lock.py 释放conversation锁
```

---

### 3.4 @个体特化流程

```
群聊中用户单独 @Claude 追问（不触发其他Agent）
│
├─ chat_service.py 识别 mention_ids 长度==1，mode==group
│    → @个体特化路由
│
├─ services/thread_service.resume_or_create(agent_id, conversation_id)
│    查该会话里该Agent是否有已有Thread
│    有 → 复用，追加当前消息到该Thread上下文
│    没有 → 新建Thread，不触发Orchestrator
│
├─ 走正常 skill→prompt→adapter 链路
│    只产生被@Agent的气泡
│    其他Agent不参与，不打扰
│
└─ message_service写回 + stream_service SSE推前端
     前端只新建该Agent气泡，其余Agent气泡不变
```

### 3.5 对话式局部修改流程

```
用户在前端选中代码段 → 输入修改意图
ChatRequest携带：
  content: "把这个函数改成异步的"
  selected_range: {file:"src/api.py", start:10, end:25, code:"...原始代码..."}
│
├─ chat_service.py 识别 selected_range 不为空 → 局部修改模式
│
├─ services/prompt_service.py 加载 prompts/local_edit.md 模板
│    渲染：
│      "以下是 {{file}} 第{{start}}-{{end}}行：\n{{selected_code}}\n
│       用户要求：{{user_intent}}\n
│       只修改上述代码段，输出完整替换内容"
│
├─ 走单聊/群聊流程（prompt已特化）
│
└─ Agent回复含修改后代码
     → diff_service 生成diff
     → DiffCard推前端
     → 用户确认 → diff_apply_service写入文件
```


### 3.9 熔断器状态机

```
CLOSED（正常）
  调用成功 → 保持CLOSED，reset failure_count
  调用失败 → failure_count++
  failure_count >= 5 → 进入OPEN

OPEN（熔断）
  所有调用直接返回熔断错误，不发真实请求
  orchestrator_service降级：用其他可用Agent完成任务
  等待reset_timeout（默认60s）→ 进入HALF_OPEN

HALF_OPEN（探测恢复）
  放行1个请求试探
  成功 → CLOSED，reset failure_count
  失败 → OPEN，重新计时
```

## 五、SSE事件协议（全局统一）

```
// Agent开始说话（前端创建新气泡）
data: {"type":"agent_start","agentId":"claude","agentName":"Claude","messageId":"msg_1"}

// 普通token流（追加到对应气泡）
data: {"type":"token","agentId":"claude","messageId":"msg_1","content":"你好"}

// 产物：网页/代码预览卡片
data: {"type":"artifact_html","agentId":"claude","messageId":"msg_1","previewUrl":"..."}

// 产物：Diff卡片
data: {"type":"artifact_diff","agentId":"codex","messageId":"msg_2",
       "file":"src/api.py","additions":5,"deletions":2,"patch":"..."}

// 审批请求（前端渲染Action按钮，Thread暂停等待）
data: {"type":"approval_request","agentId":"codex","messageId":"msg_2",
       "action":"run_command","detail":"npm install"}

// 部署进度
data: {"type":"deploy_progress","stage":"building","percent":30}
data: {"type":"deploy_done","url":"https://xxx.vercel.app"}

// Agent完成
data: {"type":"agent_done","agentId":"claude","messageId":"msg_1"}

// Agent出错
data: {"type":"agent_error","agentId":"claude","messageId":"msg_1","error":"timeout"}

// 本轮所有Agent完成
data: {"type":"round_done"}
```
